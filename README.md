# Meet-n-Hook UK Landing Page

Simple responsive landing page for GitHub Pages.

## Deploy

1. Create a GitHub repository.
2. Upload:
   - index.html
   - style.css
   - script.js
3. Go to:
   Settings → Pages
4. Select:
   Deploy from Branch
5. Choose:
   main / root
6. Save.

Your landing page will be live in a few minutes.
